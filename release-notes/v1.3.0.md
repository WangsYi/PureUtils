<!-- en:start -->
- **New PureMonitor Plugin**: Compact taskbar monitor strip, edge-docked collapsible floating pill (1–2 selectable metrics), and full hardware/sensor dashboard.
- **Hardware Sensors & Game FPS HUD**: One-click PawnIO download & silent installation for CPU/GPU/disk temps and power (plus driver-free AMD ADL / NVML) and a zero-injection ETW game FPS overlay.
- **Elevated Relaunch & UAC-Free Autostart**: One-click restart as Administrator and optional elevated logon auto-start via Windows Task Scheduler (no UAC prompt at boot).
- **Cleaner UI & Lower Memory**: Compact hover info tooltips across Settings, reduced background memory footprint, and fixed overlay z-order glitches with context menus and tray clicks.
