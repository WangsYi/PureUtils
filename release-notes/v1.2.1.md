- **Redesigned Minimal Windows 11 Installer**: Overhauled the installer UI with a seamless adaptive Light/Dark title bar, a compact centered Hero landing screen (one-click Install / Upgrade / Reinstall), a unified Custom Options page (install folder, modular components, desktop shortcut, and autostart), crisp 2× HiDPI rounded indigo CTA buttons, and removal of redundant wizard pages and control bleed-through.
- **Fixed Blank & Stalled Preparing Screen**: Added a centered preparing-status screen aligned with the progress view, switched running-instance detection to WMI so non-running installs never cold-start `PureUtils.exe --exit` or trigger unnecessary Windows security/Restart Manager scans (with `CloseApplicationsFilter=*.exe,*.dll`), and replaced synchronous button triggers with re-entrancy-guarded async `PostMessage` dispatch.
- **Release Smoke Testing & Bilingual Release Notes**: Added automated silent install/uninstall smoke tests and structured bilingual Chinese/English release note generation to the Release workflow.
