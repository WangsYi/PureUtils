- **Native Unified `pureimage_codecs.dll` Engine for PureImage**: Cross-compiled via GitHub Actions combining `libjpeg-turbo`, `libwebp`, `dav1d`/`libavif`, `libde265`/`libheif`, and `libjxl`—replacing all WASM decoders (`gen2brain/*` + `wazero`) and legacy `turbojpeg.dll` with zero third-party runtime DLLs (imports only `kernel32.dll` and `msvcrt.dll`).
- **Unified Single-EXE Installer & Smaller Footprint**: Removing WASM cuts ~10 MB from `PureUtils.exe`; the installer now ships one `PureUtils.exe` plus optional `pureimage_codecs.dll` under the PureImage component (symmetric with `PureVideo` + `libmpv-2.dll`) and cleans up legacy `turbojpeg.dll` on upgrade.
- **License Compliance & Reproducible Builds**: Decode-only build with 100% AGPL-3.0-compatible upstream libraries (zero GPL-2.0-only encoders), full upstream license notices archived in `LICENSES-pureimage-codecs.txt`, and updated `THIRD_PARTY_NOTICES.md`.
